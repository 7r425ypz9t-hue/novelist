# كاتب — Kateb

> الاسم السابق في وثائق المواصفات: «استوديو ذكاء الرواية» (NIS). المعرّفات التقنية الداخلية (الحزمة `nis`، متغيرات `NIS_*`) أُبقيت كما هي حفاظاً على توافق النشر.

تطبيق عربي أولاً يساند الروائي في التخطيط والتأليف والتحرير والتحقق والنقد والإخراج، مع بقاء **كل نصٍّ وكل قرار** في يد المؤلف: الوكلاء يقترحون، والمؤلف وحده يقبل.

> بُني وفق حزمة المواصفات المرجعية 1.0 (المحفوظة في `docs/spec/`) بعد مراجعتها نقدياً وتحسينها — انظر **[`docs/SPEC_REVIEW.md`](docs/SPEC_REVIEW.md)**.

## ما يعمل الآن

| الوحدة | المحتوى |
|---|---|
| غرفة الكتابة | محرر Tiptap باتجاه RTL مع فقرات LTR، حواشٍ، بحث واستبدال، عدّاد كلمات عربي مطابق للخادم، حفظ محلي فوري + مزامنة آمنة بـ `If-Match`، مراجعات ثابتة وفروق واستعادة، سلة محذوفات، استيراد DOCX/MD/TXT |
| الكتاب المرجعي | شخصيات، أماكن، أحداث بزمن القصة وترتيب السرد (مجهول/تقريبي/نطاق)، علاقات، حقائق بحالات معرفية: كانون/مسودة/فرضية/خارجي |
| الاستمرارية | 11 قاعدة بشواهد نصية قابلة للفتح، إعفاء مسبب يبقى عبر الفحوص |
| المصادر | PDF/DOCX/TXT/MD بحقوق وموافقة، استرجاع عربي مقيّد بالمشروع، استشهاد بالصفحة والفقرة أو «غير متحقق»، عزل محاولات حقن التعليمات |
| الوكلاء | A00–A12 بـ 21 مهارة (17 تعمل بلا أي نموذج)، تشغيل قابل للإلغاء وغير مكرِّر، تقرير تحريري يفصل الموضوعي عن الذوقي |
| غرفة النقد | مقترحات بفروق ومبرر وشواهد ودرجة يقين: قبول / رفض / تعديل قبل القبول |
| الإخراج | DOCX وPDF وEPUB 3 وMarkdown بخط Noto Naskh Arabic (OFL) وفهرس وحواشٍ |
| الخصوصية | مزود النماذج معطّل افتراضياً، موافقة مشروع + إقرار تشغيل للنقل الخارجي، تصدير كامل للبيانات واستعادة متحقق منها، حذف نهائي معلن الاحتفاظ |
| لوحة المسؤول | صحة الخدمة، قياسات، مستخدمون، سجل تدقيق منقّح، عناوين المشاريع الخاصة محجوبة |

## البدء السريع

```bash
scripts/dev.sh --demo
# الواجهة: http://localhost:5173 — الدخول: demo@nis.local / demo-password-2026
```
النشر بـ Docker وPostgreSQL والنسخ الاحتياطي: [`docs/operations.md`](docs/operations.md).

## الاختبارات

```bash
cd apps/api && pytest -q                     # 60 اختباراً (SQLite) — وتمرّ على PostgreSQL 16 بضبط NIS_DATABASE_URL
cd apps/web && npm test && npm run typecheck && npx vite build && npx playwright test   # وحدات + 3 سيناريوهات متصفح
```
مصفوفة التتبع بين كل متطلب وملف تنفيذه واختباره وحالته الصادقة: [`docs/traceability.md`](docs/traceability.md).
