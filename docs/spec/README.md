# Novel Intelligence Studio (NIS)

نسخة المواصفات المرجعية 1.0 — 13 أكتوبر 2026

## الغاية
تطبيق عربي أولاً لمساندة الروائي في التخطيط والتأليف والتحرير والنقد والتحقق والإخراج للنشر، يحفظ سيادة المؤلف على كل نص وتعديل. هذه وثائق تصميم وليست تطبيقاً منفذاً.

## الملفات
- `SYSTEM_SPEC.md`: التحليل الكامل للمتطلبات والمعمارية والبيانات والاختبارات.
- `MASTER_PROMPT.md`: الاستدعاء التنفيذي لبناء التطبيق بواسطة وكيل برمجي.
- `AGENTS.md`: أدوار الوكلاء والمهارات وحقوق الوصول وتسليم العمل.
- `CLAUDE.md`: تعليمات تنفيذ المشروع الآلية، قابلة للاستخدام في Claude Code أو تعديلها لغيره.
- `ACCEPTANCE_TESTS.md`: معايير القبول والسيناريوهات اللازمة قبل الإعلان عن اكتمال النظام.

## أولوية التنفيذ
نفذ شريحة رأسية كاملة أولاً: إنشاء مشروع ← فصل ← مشهد ← تحرير ← حفظ إصدار ← استرجاع ← تصدير؛ ثم أضف باقي الوحدات دون استبدال الشيفرة الحقيقية بواجهات وهمية.
